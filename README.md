# 📊 Power BI Sales & Return Analysis Dashboard

## Project Overview

This project contains two interactive dashboards developed in Power BI using the Superstore dataset.

### Sales Analysis Dashboard

The Sales Analysis dashboard provides insights into:
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Sales by Category & Sub-Category
- Profit by Sub-Category
- Sales by Segment
- Sales by State
- Monthly Sales Trend

### Return Analysis Dashboard

The Return Analysis dashboard provides insights into:
- Total Orders
- Returned Orders
- Return Rate
- Returned Sales
- Returned Profit
- Returns by Region
- Returns by Ship Mode
- Returns by Year
- Returns by Sub-Category

## Tools Used

- Power BI Desktop
- DAX
- Data Modeling
- Interactive Slicers
- Data Visualization
